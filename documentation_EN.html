Product Overview

What Academate is

Academate is a digital class basecamp for academic students. It gives each class one reliable place for important context, deadlines, shared materials, member activity, and live collaboration.

The main purpose is simple: every class should have a single shared place where members know what is happening, what is due, what has been shared, and where to continue working together.

The promise

  • Reduce scattered class information across chat apps, personal reminders, file links, and separate documents.
  • Keep classmates aligned through class workspaces, task tracking, schedules, discussion, files, and notes.
  • Make academic collaboration feel light, friendly, and organized without forcing students into a complicated system.
  • Support daily check-ins as well as longer semester workflows.

What makes it different

Academate is not only a task list or a chat room. It connects class identity, members, deadlines, notes, media, meetings, and schedules so students can move from information to action without losing context.

Audience

Who Academate is made for

Academate is primarily designed for students and academic peer groups, while still being flexible enough for class representatives, project teams, study clubs, and academic communities.

Students

Track classes, tasks, schedules, notes, deadlines, profile information, and daily academic context from one place.

Class organizers

Create class spaces, share join codes, maintain member lists, update class details, and coordinate tasks or notes.

Project groups

Use discussion, shared files, meeting access, task progress, and class notes to manage group deliverables.

Positioning:Academate is a student-led collaboration hub. It works alongside official university systems by helping classmates manage everyday coordination that often happens outside formal academic portals.

Sending messages

  • 1Open a class workspace.
  • 2Use the Diskusi Kelas text area labeled Ketik pesan.
  • 3Press Enter to send quickly, or use Shift+Enter for a new line when supported.
  • 4Use Terbaru to jump to the latest messages.

Attaching files

  • Click the attachment button beside the message box.
  • Images are compressed automatically before being sent.
  • Documents have a size limit of about 750 KB.
  • Supported document types include PDF, Word, Excel, PowerPoint, text, and ZIP files.

Deleting or retracting messages

You can retract your own message. The class creator can hide or retract messages as an admin action. Retracted messages remain as placeholders such as “Pesan ditarik” or “Pesan ditarik oleh admin” so the conversation timeline remains understandable.

Use discussion for quick coordination. Use shared notes for structured information that should be easy to revisit later.

Membership and Safety

Leave classes carefully

Class membership and danger-zone actions can remove access or permanently delete account data, so they should be used carefully.

Leave a class

  1. Open Akun

    Find Keanggotaan Kelas.

  2. Choose Tinggalkan

    Read the confirmation dialog carefully.

  3. Confirm leaving

    The class is removed from your joined class list and access is removed where possible.

Delete account

  1. Open Zona Berbahaya

    Find the account deletion area.

  2. Click Hapus Akun

    Read the warning and confirm only if you truly want permanent deletion.

  3. Re-authenticate if needed

    Google may require recent login before deletion completes.

Troubleshooting

When something does not work

Use this section when something does not appear, does not save, or does not behave as expected.

Cannot sign in
Allow pop-ups, use a Google account, refresh the page, and try again. If the popup closes, repeat the sign-in flow.
Class code not found
Check the code, remove extra spaces, ask the creator to resend it, or use the invitation link.
Class does not appear after joining
Refresh Kelas or open Akun and use Muat Ulang in the membership section.
Schedule is wrong
Ask the class creator to edit class day, start time, or end time in class settings. Jadwal is generated from class data.
Task missing
Check Active/Selesai tabs, class filter, search keyword, and whether you joined the correct class.
File upload fails
For documents, reduce the file below about 750 KB. For images, try a smaller image if compression still fails.
Meeting fails
Allow camera and microphone permissions, use a modern browser, reload the class page, and try again.
Telegram not connected
Open Akun, click Hubungkan or Hubungkan Ulang, start the bot, then refresh Account.
Cannot remove a member
Only the class creator can remove members from a class.
Cannot edit or delete a class
Only the class creator sees and uses class settings and delete controls.
Cannot delete account
Google may require recent login. Re-authenticate through the popup and try again.

Privacy and Responsible Use

Know what classmates can see

Academate is a collaboration space. Anything shared inside a class should be treated as visible to members of that class unless the interface clearly says otherwise.

Profile visibility
  • Display name and avatar are used in discussions, member lists, task completion, and profile cards.
  • University, major, and semester can appear in member profile views.
  • Instagram and Spotify links appear only if you add them.
  • Email can appear in profile details and meeting user info depending on context.
Class content visibility
  • Class discussion messages are for class members.
  • Shared files are collected in Media & File.
  • Shared notes are visible from Catatan Bersama.
  • Task completion may show who marked a task complete.
Responsible sharing:Do not upload private documents that classmates should not see, do not add someone else’s social URL, do not delete class data without warning, and do not use meetings to pressure or surprise classmates.
Best Practices

Make the workspace reliable

Academate becomes more useful when a class agrees on simple habits. The tool helps, but the group’s behavior makes the workspace dependable.

For class creators

  • Create clear, consistent class names.
  • Enter accurate day and time.
  • Share the class code early.
  • Keep class settings updated.
  • Use tasks for deadlines instead of only writing them in chat.
  • Warn members before major admin actions.

For members

  • Complete your profile.
  • Mark tasks complete only when actually finished.
  • Search Media & File before asking for a shared file.
  • Write clearly when sharing notes.
  • Summarize meeting outcomes in a note or message.

For project groups

  • Break large assignments into smaller tasks.
  • Attach supporting files to discussion messages.
  • Use shared notes as the single source of truth for decisions.
  • Use live meetings when text discussion slows down.
